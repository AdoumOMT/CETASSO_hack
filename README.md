# CETASSO — Site web associatif

## Présentation du projet :

Ce site web a été conçu en 2024, durant ma première année de formation en informatique, dans le cadre d’un concours organisé par le **CETASSO (Cercle des Étudiants Africains du Sud-Sahara à l’Oriental)**, auquel j’ai participé durant ma première année de formation en informatique.

Il s’agit de mon tout premier projet de création de site web. À cette époque, ce travail m’a permis de découvrir concrètement le développement web, de mettre en pratique mes premières connaissances et de faire mes premiers pas dans la conception d’un site internet.


## Fonctionnalités :

Le site comprend plusieurs pages :

- **Page d’accueil :** présentation de l’association et de ses objectifs.
- **Bureau exécutif :** présentation des membres du bureau de l’association.
- **Nos activités :** présentation des activités et des initiatives de l’association.
- **Membres :** présentation des pays représentés au sein de l’association, avec leurs drapeaux.
- **Page de contact :** affichage des informations de contact et formulaire permettant de préparer un message.
- **Navigation :** menu permettant de passer d’une page à l’autre.
- **Design responsive :** adaptation de l’affichage aux différentes tailles d’écran.


## Technologies utilisées :

- **HTML5** pour structurer les pages web.
- **CSS3** pour la mise en forme et la mise en page responsive.
- **JavaScript** pour les interactions et le comportement de certaines fonctionnalités.
- **Font Awesome** pour les icônes.
- **Google Fonts** pour la typographie, si utilisé dans le projet.

## Installation et lancement :

### Prérequis

Aucune installation de dépendances n’est nécessaire. Il suffit de disposer d’un navigateur web moderne.

Pour consulter ou modifier le code source, un éditeur comme Visual Studio Code est recommandé.


### Télécharger le projet 

Cloner le dépôt GitHub :

```bash
git clone https://github.com/AdoumOMT/CETASSO_hack.git
```

Accéder au dossier du projet :

```bash
cd CETASSO_hack
```

### Lancer le site

Ouvrir le fichier `index.html` dans un navigateur web.

Pour faciliter le développement, il est également possible d’utiliser l’extension **Live Server** dans Visual Studio Code.

## Limites du projet :

Ce site est un projet étudiant à vocation associative. Il s’agit principalement d’un site web statique utilisant HTML, CSS et JavaScript. Le formulaire de contact prépare un message et ne constitue pas, à lui seul, un système de messagerie avec backend.
